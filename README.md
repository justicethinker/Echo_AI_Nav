## Usage

### Running the Backend Server
Start the API to handle incoming voice data and memory processing:
```bash
uvicorn main:app --reload
```

### Running the Mobile Client
Open a separate terminal window, navigate to your Flutter directory, and run the app:
```bash
cd client
flutter run
```
